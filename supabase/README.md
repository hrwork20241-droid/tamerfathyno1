# ربط NO1 بقاعدة البيانات (Supabase)

لوحة التحكم بتحفظ المنتجات في Supabase، وهي قاعدة بيانات أونلاين مجانية.
الخطوات دي بتتعمل **مرة واحدة بس**، في حوالي 10 دقايق.

## 1. اعمل مشروع
1. افتح https://supabase.com واضغط **Start your project**، وسجّل دخول بحساب GitHub.
2. اضغط **New project**:
   - **Name:** `NO1`
   - **Database Password:** اكتب كلمة سر قوية واحفظها عندك
   - **Region:** اختار أقرب منطقة ليك (مثلاً **Frankfurt**)
3. اضغط **Create new project** واستنى دقيقتين لحد ما يجهز.

## 2. جهّز الجدول والصور
1. من القايمة الجانبية افتح **SQL Editor**، واضغط **New query**.
2. انسخ كل محتوى الملف `supabase/setup.sql` والصقه.
3. في **آخر سطر**، غيّر `your-email@example.com` لبريدك الإلكتروني. ده الحساب اللي هيقدر يعدّل المنتجات.
4. اضغط **Run**، ولازم تظهر رسالة **Success**.

## 3. اعمل حساب الدخول للوحة التحكم
1. افتح **Authentication** ← **Users** ← **Add user** ← **Create new user**.
2. اكتب **نفس البريد** اللي حطيته في الخطوة 2، وكلمة سر للوحة التحكم.
3. علّم على **Auto Confirm User**، واضغط **Create user**.
4. (مستحسن) من **Authentication** ← **Sign In / Providers**، اقفل **Allow new users to sign up**، علشان محدش غيرك يعمل حساب.

## 4. ابعت المفتاحين
افتح **Project Settings** ← **API** (أو **Data API**) وانسخ:
- **Project URL** (شكله `https://xxxx.supabase.co`)
- **anon public** key (نص طويل بيبدأ بـ `eyJ`)

ابعتهم، أو حطهم بنفسك في `app/src/config.ts`. المفتاحين دول آمنين ينزلوا مع التطبيق،
لأن قواعد الحماية في `setup.sql` بتسمح للعملاء يشوفوا المنتجات الظاهرة بس، وبريدك بس هو اللي يقدر يعدّل.

> ⚠️ ماتبعتش ولا تنشر **service_role** key ولا كلمة سر قاعدة البيانات.
